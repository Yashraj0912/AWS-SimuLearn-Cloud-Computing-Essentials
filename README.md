## 📖 Overview

This repository documents my completion of the **AWS SimuLearn: Cloud Computing Essentials** assignment.

AWS SimuLearn combines **AI-powered business simulations** with **hands-on AWS labs**, allowing learners to solve real-world business challenges while gaining practical experience in the AWS Management Console.

In this assignment, I worked with a fictional customer to improve the **reliability of a beach wave conditions website** by designing and implementing an AWS cloud solution.

---

## 🎯 Business Scenario

The web team required a reliable solution to improve the availability of their **Beach Wave Conditions** webpage.

As a Cloud Engineer, I was responsible for:

- Understanding customer requirements
- Designing an AWS-based solution
- Communicating the proposed architecture
- Deploying the solution using AWS services
- Validating the deployment in a live AWS environment

---

## 🚀 Learning Outcomes

During this simulation, I learned to:

- Identify the key characteristics of AWS Cloud computing
- Analyze the benefits of AWS services
- Compare AWS Cloud infrastructure with traditional on-premises infrastructure
- Design cloud-based solutions for business requirements
- Deploy and validate solutions in the AWS Management Console
- Host a static website using Amazon S3
